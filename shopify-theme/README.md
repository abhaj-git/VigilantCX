# SVANK Shopify theme

Custom Shopify Online Store 2.0 theme for `svankshop.myshopify.com`.

## Preview

Open `preview/index.html` for a static design preview. Shopify products, menus, checkout, policies, and theme-editor settings become active after the theme is uploaded.

## Upload

1. Zip the contents of this directory (not the directory itself).
2. In Shopify, go to **Online Store → Themes → Import theme → Upload zip file**.
3. Preview the theme before publishing.
4. In **Customize**, select the logo, homepage collection, menus, and final imagery.

With Shopify CLI installed, the theme can instead be previewed with:

```bash
shopify theme dev --store svankshop.myshopify.com
```

Do not publish until product prices, inventory, shipping, returns, taxes, payments, and checkout have been reviewed.
